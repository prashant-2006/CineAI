# CINE.AI | Neural Recommendation Engine

A classified cinematic intelligence database. **CINE.AI** is a premium, dark-themed movie tracking and recommendation system inspired by the stark, gritty aesthetic of the 2022 *The Batman* film. 

Ultimately powered by Gemini AI, this system will track your active watchlist, save your cinematic masterpieces, and predict your next obsession based on your viewing patterns.

## 🗄️ Tech Stack

*   **Framework:** [Next.js](https://nextjs.org/) (App Router)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Icons:** [Lucide React](https://lucide.dev/)
*   **Data Source:** [OMDb API](https://www.omdbapi.com/)
*   **AI Engine:** Google Gemini (Integration Upcoming)
*   **Backend:** Node.js / Express / MongoDB (Integration Upcoming)

## 🦇 Features

*   **Cinematic Interface:** A deep black, high-contrast UI featuring custom atmospheric particle animations ("cinematic ash").
*   **Tactical Navigation:** Fully responsive, full-screen mobile routing with precision hover states.
*   **Secure Database Querying:** Backend API proxies built in Next.js to securely fetch movie data without exposing API keys.
*   **Actionable Intelligence:** Tactical hover menus on movie cards to quickly assign titles to your *Target List* (Watchlist), *Favorites*, or *Active Intel* (Currently Watching).
*   **Premium Fallbacks:** Custom UI states for classified or missing visual data.
